what I'm working on

Piano From Above for KaiOS

A Black MIDI visualizer for KaiOS 2.5, designed specifically for low-end smart feature phones.

The project focuses on making extremely dense MIDI tracks playable on hardware with limited CPU, RAM, and graphics performance.

  • Black MIDI rendering optimization
  • Canvas performance
  • Lightweight WebAudio synthesizer
  • Rendering improvements
  • Physical keypad controls
  • Memory optimization
  • Audio and playback fixes
